# **Projeto TUTO — Plataforma de Tutoriais**

O TUTO é um site colaborativo criado em grupo 👥 com o objetivo de disponibilizar tutoriais simples, organizados e acessíveis sobre diversos temas. O projeto foi desenvolvido com foco em clareza, permitindo que novos conteúdos e funcionalidades sejam adicionados facilmente 😊.

## 🎯 Objetivo do Projeto
O TUTO pretende centralizar tutoriais de forma intuitiva, ajudando utilizadores a aprender rapidamente sobre diferentes tópicos. O site foi pensado para ser leve, responsivo e fácil de navegar.

🧩 Funcionalidades Principais
- Página inicial com destaque para tutoriais recentes ou populares.
- Organização dos tutoriais por categorias.
- Páginas individuais para cada tutorial, com estrutura clara e visual limpa.
- Navegação simples e responsiva para dispositivos móveis.
